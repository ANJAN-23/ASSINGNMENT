# GitHub Profile Analyzer API

## Features

- Fetch GitHub profile
- Store profile data in MySQL
- Calculate useful insights
- View all analyzed profiles
- View single analyzed profile

## Insights Stored

- Followers
- Following
- Public Repositories
- Total Stars
- Total Forks
- Most Used Language
- Follower Ratio
- Popularity Score
- Account Age

## Installation

npm install

Create .env file

DB_NAME=
DB_USER=
DB_PASSWORD=
DB_HOST=

PORT=4000

Run

npm start
